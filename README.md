# ⚙ Инженер — ИИ-ассистент по подбору трубопроводной арматуры

Внутренний сайт-чат на модели Claude (Anthropic). Второй бот группы компаний, собран на том же
каркасе, что и «Юрист», но со своей ролью, методикой, базой знаний и адресом.

**Что умеет**
- Подбирает арматуру по условиям: среда, температура, давление, DN, присоединение, привод
- Проверяет химическую совместимость материалов корпуса, затвора, седла, уплотнений и крепежа
- Назначает класс герметичности по ГОСТ 9544-2015 и обосновывает выбор типа арматуры
- Переводит марки материалов между ASTM, EN и ГОСТ
- Сам ищет действующие редакции стандартов и данные производителей и показывает источники
- Разбирает присланные файлы: опросные листы, ТЗ, спецификации (PDF, DOCX, TXT, фото)
- Собирает готовые документы Word на бланке Белвен или Армета и правит присланные .docx
- Запоминает ваши правила через «запомни: …»
- Вход по общему паролю, история диалогов — в браузере сотрудника, тёмная и светлая темы

Проект без внешних npm-зависимостей — собирать нечего, деплой проходит за минуту.

## Запуск на Vercel (≈10 минут)

Это **отдельный проект**, не трогающий бота-юриста. Нужен свой репозиторий и свой проект на Vercel.

1. **Создайте новый репозиторий на GitHub** (например `inzhener-bot`) и загрузите туда содержимое
   этой папки: github.com → New repository → «uploading an existing file» → перетащите все файлы и папки.
2. Зайдите на **vercel.com** → *Add New… → Project* → выберите новый репозиторий → *Import*.
   Framework Preset: **Other**. Остальное не трогайте.
3. Перед нажатием *Deploy* откройте **Environment Variables** и добавьте:

   | Переменная | Значение |
   |---|---|
   | `ANTHROPIC_API_KEY` | тот же ключ `sk-ant-…`, что у юриста |
   | `STAFF_PASSWORD` | **свой** пароль для этого бота (несколько — через запятую) |
   | `SESSION_SECRET` | новая длинная случайная строка, не та же, что у юриста |
   | `ANTHROPIC_MODEL` | *(необязательно)* зафиксировать модель, например `claude-opus-5` |

4. **Deploy**. Через минуту получите адрес вида `inzhener-bot.vercel.app`.

> Переменные добавили после деплоя — сделайте *Deployments → … → Redeploy*.

Ключ API можно брать тот же: расход по обоим ботам виден общей суммой в console.anthropic.com → Usage.
Пароль и `SESSION_SECRET` лучше разные — тогда доступ к ботам раздаётся независимо.

### Какая модель отвечает
По умолчанию `claude-opus-5`. Если она недоступна для ключа, сайт сам переходит к следующей
из списка в `api/chat.js`: `claude-opus-4-6` → `claude-opus-4-5` → `claude-sonnet-4-5`.
Зафиксировать — переменной `ANTHROPIC_MODEL` или полем «Модель» в настройках.

## Настройки: всё в руках инженера

Кнопка **«Настройки»** в левой панели. Восемь вкладок:

- **Правила** — методика подбора: сбор исходных данных, химическая совместимость, выбор типа,
  класс герметичности, материалы, проверка по стандартам, форма ответа. Дословные формулировки
  берите в кавычки — они попадут в документы без изменений.
- **Роль и стиль** — кто ассистент, насколько подробно отвечает, как ссылается на стандарты.
- **Компания** — реквизиты, подписанты, чем занимаемся.
- **Модель и поиск** — модель, длина ответа, «глубокое рассуждение», веб-поиск и список
  доверенных сайтов (docs.cntd.ru, protect.gost.ru, nibco.com, buerkle.de и др.).
- **Чек-лист** — по нему ассистент проходит перед каждой выдачей: среда и температура, давление,
  герметичность, присоединение, привод, документы.
- **Бланки** — Белвен (Меркулов) и Армета (Шмалько): реквизиты, подписанты, логотипы.
- **Память** — правила, которые бот должен помнить всегда.
- **Быстрые кнопки** — плитки на главном экране.

Настройки хранятся в браузере и применяются со следующего вопроса. Внизу окна **Экспорт** и
**Импорт** — перенести на другой компьютер или сделать резервную копию.

## Память

Напишите в чат «запомни: на пар всегда ставим клиновую задвижку с графитовым сальником» — бот
вызовет инструмент `remember`, под ответом появится плашка «Запомнил: …». Записи видны списком
во вкладке «Память», правятся и удаляются там же. Хранятся в браузере (`eb_settings`), на сервере
не остаются.

## База знаний

Левая панель → **«📚 База знаний»**. Что загрузить в первую очередь — в папке
`для-загрузки-в-базу-знаний/`, там же README с разбором по каждому файлу и важным замечанием
про ГОСТ Р 54808-2011 (скан, заменён на ГОСТ 9544-2015).

- Форматы: PDF, DOCX, TXT, MD, CSV, изображения. До 4 МБ на файл.
- Галочка у файла временно исключает его из ответов, не удаляя.
- Файлы видны всем, кто знает пароль.

## Документы

Бот собирает .docx на бланке компании: опросные листы, технические предложения, спецификации
подобранной арматуры, технические требования, письма. Под каждым документом кнопки:
Скачать, PDF, PNG, Посмотреть. Присланный .docx (опросный лист заказчика, ТЗ) правит прямо
в файле: новая редакция жёлтым, старая — зачёркнутой, оформление не ломается.

Принятые по умолчанию параметры бот помечает жёлтым, чтобы заказчик их проверил.

## Чем отличается от бота-юриста

| | Юрист | Инженер |
|---|---|---|
| Адрес | yurist-bot-beige.vercel.app | свой, отдельный |
| Акцент интерфейса | латунь | сталь-синий |
| Роль | договорная работа | подбор арматуры |
| Правила | критерии протокола разногласий | методика подбора |
| Чек-лист | гарантия, расторжение, ответственность, приложения | среда, давление, герметичность, присоединение, привод, документы |
| Документы | протоколы разногласий, договоры, претензии | опросные листы, техпредложения, спецификации |
| Ключи в браузере | `lb_*` | `eb_*` — настройки двух ботов не пересекаются |

Каркас общий: вход, чат, стриминг, база знаний, память, генерация и правка .docx. Поэтому
исправление в одном проекте легко переносится в другой — файлы те же.

## Ограничения
- Vercel принимает запросы до 4,5 МБ: вложение в чате и файл базы знаний — примерно до 3–4 МБ.
- Старый `.doc` не поддерживается — сохраните как `.docx` или PDF.
- История хранится в браузере конкретного сотрудника.
- Длинные ответы с поиском идут 1–3 минуты; лимит функции 300 с задан в `vercel.json`.

## Свой сервер
```
cp .env.example .env   # заполните
node server.js         # http://localhost:3000
```

## Структура
```
public/                      интерфейс (index.html, app.js, style.css, логотипы)
api/chat.js                  запросы к Claude: стриминг, веб-поиск, база знаний, инструменты
api/files.js                 загрузка/список/удаление файлов базы знаний
api/login.js                 вход по паролю
lib/settings.js              значения по умолчанию: роль, методика, чек-лист, бланки, кнопки
lib/prompt.js                сборка системной инструкции
lib/docxgen.js               сборка .docx на бланке
lib/docxedit.js              правки в присланный .docx
для-загрузки-в-базу-знаний/  стартовый набор — загрузить через сайт один раз
knowledge/                   необязательная «вшитая» папка, обычно пустая
```
