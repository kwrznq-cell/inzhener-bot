# Папка knowledge/

Необязательная. Сюда кладут документы, которые должны быть частью сборки — всегда на месте,
независимо от аккаунта Anthropic. Файлы отсюда подставляются в каждый диалог автоматически.

Обычно папка пустая: живая база знаний ведётся через кнопку «📚 База знаний» на самом сайте,
и обновлять её там проще — код и деплой не трогаются.

Форматы: .md, .txt, .csv. Помните, что всё содержимое уходит в каждый запрос — не кладите сюда
много и не кладите большие файлы.
