## Чего здесь нет и почему

**ГОСТ Р 54808-2011 «Нормы герметичности затворов».** Ваш файл — скан без текстового слоя,
3,9 МБ, 45 страниц. Два отдельных препятствия:

1. Распознавание (OCR) числовые таблицы портит. В проверочном прогоне нормы утечек вышли
   как `0,0060№` вместо `0,0006·DN`, а в таблицах рекомендаций по классам пропали все отметки «+».
   Такой файл опаснее, чем его отсутствие: ассистент будет уверенно называть неверные цифры.
2. Загрузить скан как есть можно — модель прочитает страницы как изображения, точно, но
   медленно и заметно дороже, и файл почти упирается в лимит 4 МБ.

**Главное: ГОСТ Р 54808-2011 заменён на ГОСТ 9544-2015.** Классы герметичности ассистент
назначает по 9544-2015, и именно его стоит найти в текстовом виде (не сканом) и загрузить
первым номером. 54808 нужен только там, где на него прямо ссылается договор или проект.
